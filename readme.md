# Event Management System

A web-based event management system for event organization, attendee registration, ticket management, and event check-in.

## Objectives

The project aims to build a practical event management system while studying and applying modern web development technologies, with a focus on backend development using FastAPI.

The main objectives are:

* Manage and organize events.
* Allow users to register for events.
* Manage event tickets and attendee information.
* Support event check-in.
* Apply modern backend development practices.
* Study and apply FastAPI in building RESTful APIs.
